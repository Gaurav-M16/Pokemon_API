# 🐾 PokéAPI CLI Project

A simple Python command-line application that uses the PokéAPI to fetch Pokémon information interactively.

## 🚀 Features

- Displays 20 Pokémon names
- Takes user input for Pokémon selection
- Fetches Pokémon details using API
- Shows:
  - Height
  - Weight
  - Pokémon Type
  - First 10 Moves
- Uses loading delays for better CLI experience

---

## 🛠 Technologies Used

- Python
- requests
- time
- PokéAPI

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Gaurav-M16/Pokemon_API.git
```

Go to project folder:

```bash
cd POKEMON_PROJECT
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python main.py
```
